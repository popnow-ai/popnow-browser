# Store listing

**Name:** PopNow: AI Image and Video Generator

**Short description:** Generate AI images and videos from any page with Nano Banana, Seedream, Kling, Veo and more. See the price before every run.

**Description:**

PopNow puts AI image and video models one click away. Write a prompt or select text on any page, pick a model and see the price before anything is charged.

- Models include Nano Banana, GPT Image, Seedream, FLUX, Kling, Seedance, MiniMax H3 and Veo
- See the maximum charge and confirm it before every run
- Right-click selected text to use it as a prompt
- Tasks keep running if you close the popup
- Failed jobs are refunded automatically

Requires a PopNow account and API balance. Create an API key at https://popnow.ai/api

**Website:** https://popnow.ai/api
**Support:** support@popnow.ai
**Privacy policy:** https://popnow.ai/privacy

**Single purpose (Chrome):** Generate images and videos with the PopNow API from a prompt the user writes or selects.

**Permission justifications (Chrome):**

- `storage`: keeps the user's API key and the ID of a running task.
- `contextMenus`: adds "Generate with PopNow" to selected text.
- `downloads`: saves a generated file when the user clicks Download.
- Host `https://api.popnow.ai/*`: calls the PopNow API.
