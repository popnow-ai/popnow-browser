# Privacy

The PopNow browser extension has no analytics and reads no page content by itself.

- **Your API key** is stored in the browser's local extension storage and is sent only to `api.popnow.ai` to authenticate your requests.
- **Your prompt** is sent to `api.popnow.ai` when you ask for a price or start a generation. Text from a page is used only when you select it and choose **Generate with PopNow**.
- **Generated files** are loaded from PopNow's storage and saved only when you click Download.

PopNow's handling of requests is covered by its [privacy policy](https://popnow.ai/privacy).
