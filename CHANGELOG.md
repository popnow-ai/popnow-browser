# Changelog

## 0.2.0

- Sign in with your PopNow account. Prices and balance show in credits.
- Right-click an image: Edit image, Animate, Remove background, Upscale, Expand, Relight, Apply effect and Save to my library.
- Images without a public link are read from the page and uploaded to your account.
- The price is shown on the button before every run; a changed price is asked again, never raised for you.
- Pick a model for prompts, see My creations, download, copy the link or save a result to your library.
- Long creations keep going after the popup closes, with a notification when they're ready.
- API keys still work under Developers and bill in USD.

## 0.1.0

- First release: prompts to images and videos with a PopNow API key.
